# Screenshots Android

Use esta pasta para guardar screenshots reais do APK/AAB instalado em aparelho ou emulador Android.

Não use os arquivos de `assets/images/screens/` na Play Store. Eles são referências visuais internas, não capturas reais do app publicado.

## Capturas recomendadas

1. `01-onboarding.png` - tela de boas-vindas
2. `02-dashboard.png` - Início com medição registrada
3. `03-add-measurement.png` - Nova medição
4. `04-history.png` - Histórico com filtros
5. `05-insights.png` - Insights/progresso
6. `06-reports.png` - Relatório para consulta
7. `07-reminders.png` - Lembretes
8. `08-assistant.png` - Assistente GlicoAí

## Regras

- Capturar a partir do build preview/production instalado, não do navegador.
- Usar português brasileiro.
- Evitar dados pessoais reais.
- Usar medições fictícias seguras, sem promessas médicas.
- Não mostrar e-mails, tokens, URLs internas ou dados sensíveis.
- Preferir resolução vertical de telefone Android moderno.
